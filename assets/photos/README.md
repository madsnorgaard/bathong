# Demo photographs

`johannesburg/` - street and documentary frames by Mads Nørgaard, Johannesburg
2018, from the "Johannesburg documentary photography" project on
madsnorgaard.net (served from photo.madsnorgaard.net). Used as demo frames in
the styleguide and as stand-ins in the v1 site photo slots.

These are placeholders in spirit: before launch the site's PHOTO SLOTs get
Pretoria lead frames chosen by group edit. Credit stays with the photographer
wherever a frame appears - that rule applies to demo frames too.
