Ruled index list - membership benefits, photocall rules, programme lines.

```jsx
<RuledList items={[
  { num: 'B/01', label: 'Workshops & monthly photowalks', note: 'Member pricing on every event, priority booking.' },
  { num: 'B/02', label: 'Photocalls & publication', note: 'Selected work published with full credit.' }
]} />
```

Index prefixes are meaningful: `B/` benefits, `W/` walks, `E/` exhibitions. On ink grounds the rules go hairline automatically via `.on-ink`.
