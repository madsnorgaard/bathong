Opens every page section: display title with the punch-dot, plus a mono archive index on the right.

```jsx
<SectionHead title="Photo Stories" index="02 / The work comes first" />
<SectionHead title="Manifesto" index="01 / Why we exist" dotColor="var(--signal)" />  {/* on ink */}
```

The index is a numbered running order - keep the numbering continuous down the page. On ink the dot goes signal; on jacaranda it goes paper.
