The definition card - Bathong's most portable brand asset. Use it wherever the name needs explaining: manifesto sections, Instagram slides, wall text, the back of a membership card.

```jsx
<DictionaryCard />
<DictionaryCard surface="paper" entry="bathong." pos="loc." senses={['among the people.']} />
```

Keep it mono - the whole point is that it reads like an archive card. A 1080x1080 social version ready to screenshot lives at `assets/dictionary-card.html`.
