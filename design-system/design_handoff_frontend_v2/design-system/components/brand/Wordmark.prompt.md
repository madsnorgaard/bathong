Renders the Bathong. wordmark - use it anywhere the brand states itself: masthead, footer, membership card, exhibition wall text.

```jsx
<Wordmark size="hero" as="h1" />
<Wordmark size="sm" href="#top" />
<Wordmark size="lg" dotColor="var(--signal)" />   {/* on ink, manifesto inversion only */}
```

Rules: the mark always carries the full stop, never the exclamation. `Bathong!` is the *voice* - write it as plain copy in campaign text, tickers and captions, never through this component. The dot is jacaranda by default; flip it to paper on a jacaranda ground.
